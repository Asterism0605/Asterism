# Issue #22 釐清：外部圖無限新增，到底餵哪種瀏覽模型？

> 背景：針對「外部圖庫照片會新增在 medium / subMedium，styleGroup 數量不變，但首頁是 styleGroup 主圖，往下無限新增會變成 medium/subMedium 的圖片嗎？」這個提問的釐清。
> 對應設計文件：`docs/superpowers/specs/2026-06-15-external-image-styleGroup-recognition-design.md`

---

## 先確認：說對的部分 ✅

| 提的點                      | 對不對 | 對照設計                                                                                        |
| --------------------------- | ------ | ----------------------------------------------------------------------------------------------- |
| styleGroup 數量不變         | ✅ 對  | styleGroup 是 3 個固定**錨點**，CLIP 永遠只往這 3 個分。設計裡「可成長清單」**不含 styleGroup** |
| medium / subMedium 數量會變 | ✅ 對  | 正是「做法 A」：低信心 → 人工命名 → medium/subMedium 清單長大                                   |

這兩點理解正確，跟設計文件一致。

---

## 但問題藏了一個沒講明的假設 ⚠️

> 「首頁是 styleGroup 主圖，**往下**無限新增會變成 medium/subMedium 的圖片嗎？」

這句話假設了一個**由上往下的階層瀏覽**：

```
首頁：styleGroup 主圖（最上層）
  ↓ 往下鑽
medium 的圖
  ↓ 再往下
subMedium 的圖（無限新增填在這裡）
```

這個「鑽階層」的心智模型，其實是當初 **Explore 資料庫設計的願景**（style_group → category → subcategory 一層層點下去）。

**但 develop 上實際做出來的 ImageSpread 不是這樣運作的。**

---

## 關鍵：實際實作不是「鑽階層」，是「輻射同風格」

develop 的 `getRelatedImages` 邏輯是：

```
點一張圖 → 找「同 styleGroup + 共享 style[] 最多」的圖，輻射在周圍
         → 點一張 → 它變中心，再輻射
```

它**完全沒有用到 medium / subMedium 來導航**。也就是說：

- **無限新增的圖，不是「變成 medium/subMedium 層的圖」** —— 它們是「跟你手上這張**同 styleGroup、共享 style 標籤**」的更多圖，不管 medium 是什麼。
- medium / subMedium 目前只是**掛在每張圖上的屬性（metadata）**，**不是一個瀏覽層級**。

---

## 一個概念要校正 🔧

medium / subMedium **不是另一種「圖片」**，而是**每張圖都有的標籤**：

> 一張外部圖**同時**有 styleGroup + medium + subMedium。它不是「一張 medium 圖」，而是「一張屬於某 styleGroup、且 medium=X、subMedium=Y 的圖」。連首頁的 styleGroup 主圖本身也有 medium（只是那 3 張 `*-main-*` 封面剛好是現況例外、沒填 medium）。

所以「首頁是 styleGroup 圖、底下是 medium 圖」這種**分層的圖種**並不存在 —— 它們是同一種圖，只是首頁挑了每組一張當代表。

---

## 真正要拍板的設計題 🎯

問題背後其實是個好問題：**外部圖無限新增，到底餵給哪一種瀏覽模型？**

|                        | A. 輻射同風格（develop 現況）      | B. 鑽階層 medium/subMedium（原 Explore 願景） |
| ---------------------- | ---------------------------------- | --------------------------------------------- |
| 無限新增的圖是什麼     | 同 styleGroup、共享 style 的更多圖 | 填進 medium→subMedium 分類桶                  |
| medium/subMedium 角色  | 只是 metadata                      | **是瀏覽層級**，點得下去                      |
| 首頁主圖往下           | 輻射相似圖                         | 鑽 medium → subMedium                         |
| 要不要改 develop 的 UI | 不用，接 `getRelatedImages` 就好   | 要新做分類瀏覽頁                              |

**判讀**：這個提問是用 B（原 DB 願景）在想，但目前 shipped 的是 A。issue #22 的外部圖**兩種都餵得了**（因為它三層都分類了），所以這不是「做不做得到」，是「**要走哪種瀏覽體驗**」的決定。

---

## 要大家對齊的一句話

> styleGroup 不變、medium/subMedium 會長大，這完全正確。但「往下無限新增變成 medium/subMedium 圖」這個想法，是假設了**鑽階層**的瀏覽 —— 而 develop 現在的 ImageSpread 是**輻射同風格**、沒用到 medium/subMedium 導航。
>
> **所以要先一起決定：外部圖是要餵「A 輻射相似」還是「B medium/subMedium 鑽階層」？** 決定了，後面的 spec 和實作才有依據。
