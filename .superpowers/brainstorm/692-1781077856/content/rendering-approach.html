Three.js 照片球的渲染方式

三種方法都能達到真正的 3D 近大遠小，差別在技術實現與視覺質感

REAL 3D · Z-DEPTH · PERSPECTIVE CAMERA

A  WebGL 3D Planes

照片渲染在 Three.js Canvas 上，每張照片是帶貼圖的 3D 平面。透視攝影機讓近的照片自動大、遠的自動小，深度完全隨機，視覺最立體。需要 raycasting 偵測點擊。

優點

  • 最真實的 3D 近大遠小
  • 深度感強烈
  • 背景可疊加 particle 效果

挑戰

  • 圖片需作為 texture 載入
  • 點擊要用 raycasting
CSS3DRENDERER · HTML IMG · DOM EVENTS

B  CSS3DRenderer

照片仍是 HTML <img>，由 Three.js CSS3DRenderer 在 3D 空間排列。點擊、lazy loading 全部沿用 DOM 原生行為，3D 感由 CSS perspective 提供。

優點

  • 圖片保持 HTML 元素
  • 點擊/hover 用 DOM 事件
  • lazy loading 不需改動

挑戰

  • 3D 深度感不如 WebGL 真實
  • 兩套渲染層要對齊
THREE.JS MATH · DOM IMG · 手動投影計算

C  Three.js 數學 + DOM

只使用 Three.js 的 Vector3 + PerspectiveCamera 計算 3D → 2D 投影。照片仍是 DOM 元素，由計算結果驅動 left/top/scale。完全不用 WebGL Canvas。

優點

  • 最輕量，無 WebGL 開銷
  • 照片全部 HTML，無需改動
  • 現有測試影響最小

挑戰

  • 視覺效果最接近現在
  • 進階效果（blur 霧）要手動實作
